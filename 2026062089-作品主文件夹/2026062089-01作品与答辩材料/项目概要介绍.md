# 项目概要介绍

## 项目名称
AI模拟面试与能力提升软件

## 项目背景
随着高校毕业生数量逐年增加，就业市场竞争日益激烈。大学生虽具备专业技能，但在求职面试中普遍面临缺乏经验、紧张怯场、无法精准展现个人能力、对不同岗位的面试要求不了解等问题。传统的就业指导多为一对多的讲座或有限的模拟面试，难以提供个性化、沉浸式、可反复练习的指导服务。

本项目基于人工智能技术，特别是多模态交互与智能评估技术，构建高度拟真、反馈及时、个性化定制的面试训练系统，帮助学生提升面试技巧，增强就业竞争力。

## 项目目标
开发一个“面向计算机相关专业学生的AI模拟面试与能力提升平台”，实现以下核心目标：

1. **岗位化情景模拟**：针对至少两种计算机专业岗位（如Java后端工程师、Web前端工程师）构建专属面试题库和评估模型。
2. **多模态互动面试**：通过语音、文本与AI面试官进行多轮沉浸式对话，实现动态追问和真实面试压力模拟。
3. **智能评估与反馈**：对学生的技术回答正确性、语言表达逻辑性、沟通能力、知识深度等进行多维度量化评分，生成详细评估报告。
4. **个性化提升路径**：根据历次模拟面试记录，分析能力短板，智能推荐学习资源，形成“练习-评估-提升”的闭环。

## 核心功能
1. **多岗位面试管理**：支持Java后端、Web前端等岗位的模拟面试，每个岗位拥有专属题库和评估标准。
2. **语音交互系统**：集成科大讯飞语音识别(ASR)和语音合成(TTS)功能，支持语音输入和AI语音输出。
3. **智能评估引擎**：基于大语言模型(LLM)的答案评估和问题生成，结合RAG（检索增强生成）技术提供精准的知识检索。
4. **多维度报告生成**：自动化生成结构化评估报告，包含技术能力、表达能力、逻辑思维等维度的得分和详细改进建议。
5. **历史记录与成长追踪**：记录学生的面试历史，可视化展示能力成长曲线，帮助用户了解自身进步。

## 技术架构
本项目采用前后端分离的现代化架构：

### 前端技术栈
- **框架**：Vue 3 + TypeScript
- **构建工具**：Vite
- **UI组件库**：Element Plus
- **状态管理**：Pinia
- **HTTP客户端**：axios
- **WebSocket**：socket.io-client（用于实时语音流通信）

### 后端技术栈
- **框架**：Flask 2.3+ (Python)
- **WebSocket服务**：Flask-SocketIO
- **数据库ORM**：Flask-SQLAlchemy
- **数据库**：MySQL 8.0
- **语音服务**：科大讯飞SDK
- **大模型集成**：支持DeepSeek、通义千问等主流大模型
- **向量检索**：Sentence-Transformers + ChromaDB（用于RAG）

### 系统部署
- **开发环境**：本地开发服务器（前端端口5173，后端端口8083）
- **生产环境**：支持Docker容器化部署
- **数据库**：MySQL关系型数据库 + ChromaDB向量数据库

## 创新点
1. **多模态交互融合**：将语音识别、语音合成与大语言模型深度结合，创造沉浸式面试体验。
2. **岗位化智能评估**：针对不同技术岗位定制评估模型，实现精准的能力匹配度分析。
3. **RAG增强的知识库**：构建岗位相关知识库，通过向量检索增强大模型的回答准确性和专业性。
4. **成长追踪系统**：通过可视化图表展示用户能力成长轨迹，提供数据驱动的个性化学习建议。
5. **实时语音流处理**：基于WebSocket的实时音频流传输和处理，实现低延迟的语音交互。

## 项目价值
### 对学生用户
- 提供随时可用的个性化面试教练，降低面试焦虑
- 通过反复练习和即时客观反馈，快速提升面试技巧
- 清晰了解目标岗位能力要求，针对性补齐短板

### 对高校教育
- 弥补传统就业指导的不足，提供可量化的面试训练工具
- 减轻就业指导老师的工作负担，提高指导效率
- 为高校就业质量提升提供技术支持

### 社会价值
- 促进大学生就业能力提升，缓解就业市场结构性矛盾
- 推动AI技术在教育领域的创新应用
- 为职业教育数字化转型提供实践案例
