## 快速启动

### 方式一：手动启动（推荐）

按照以下步骤依次启动各服务：

#### 1. 启动Flask后端
```bash
# 进入后端目录
cd backend/flask-backend

# 创建并激活虚拟环境（首次运行）
python -m venv venv

# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑.env文件，配置数据库和API密钥

# 初始化数据库（首次运行）
python init_db.py

# 启动服务
python run.py
```

#### 2. 启动前端
```bash
# 进入前端目录
cd frontend

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

#### 3. 访问系统
打开浏览器访问：http://localhost:5173

### 方式二：单独启动服务

如需单独启动或测试某个服务，请参考下方[服务详情](#服务详情)章节。

## 服务详情

### Flask后端

Flask后端提供完整的AI模拟面试API服务，包括语音交互、智能评估和RAG检索功能。

**基本信息：**
- 端口：`8083`
- 位置：`backend/flask-backend/`
- 健康检查：`http://localhost:8083/health`
- 主应用文件：`app/__init__.py`

**目录结构：**
```
flask-backend/
├── app/                  # 应用核心代码
│   ├── config/          # 配置文件（开发/生产环境）
│   ├── models/          # 数据模型（SQLAlchemy）
│   ├── routes/          # API路由（Blueprint）
│   ├── services/        # 业务逻辑层
│   └── utils/           # 工具函数
├── requirements.txt     # Python依赖包
├── run.py              # 应用启动脚本
├── init_db.py          # 数据库初始化
└── .env.example        # 环境变量示例
```

**依赖安装：**
```bash
cd backend/flask-backend
pip install -r requirements.txt
```

主要依赖：
- `Flask>=2.3.0` - Web框架
- `Flask-SQLAlchemy>=3.0.0` - 数据库ORM
- `Flask-SocketIO>=5.3.0` - WebSocket支持
- `mysqlclient>=2.2.0` - MySQL数据库驱动
- `requests>=2.31.0` - HTTP客户端
- `sentence-transformers` - 文本嵌入模型（用于RAG）

**启动命令：**
```bash
# 开发模式
python run.py

# 生产模式（使用gunicorn）
gunicorn -w 4 -b 0.0.0.0:8083 "app:create_app()"
```

**环境变量配置：**
需要配置以下环境变量（复制.env.example为.env并编辑）：
```bash
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_NAME=ai_interview
DB_USER=root
DB_PASSWORD=123456

# 科大讯飞配置
IFLYTEK_APP_ID=your_app_id
IFLYTEK_API_KEY=your_api_key
IFLYTEK_API_SECRET=your_api_secret

# 大模型配置
LLM_PROVIDER=deepseek
LLM_API_KEY=your_deepseek_api_key
```

**数据库初始化：**
```bash
# 确保MySQL服务已启动
# 执行初始化脚本
python init_db.py
```

### 前端服务

前端基于Vue 3 + TypeScript + Element Plus构建，提供友好的用户界面。

**基本信息：**
- 端口：`5173`
- 位置：`frontend/`
- 访问地址：`http://localhost:5173`

**目录结构：**
```
frontend/
├── src/
│   ├── api/          # API接口封装
│   ├── assets/       # 静态资源
│   ├── components/   # 通用组件
│   ├── router/       # 路由配置
│   ├── stores/       # 状态管理（Pinia）
│   ├── utils/        # 工具函数
│   ├── views/        # 页面视图
│   ├── App.vue       # 根组件
│   └── main.ts       # 应用入口
├── vite.config.ts    # Vite配置
└── package.json      # 依赖包配置
```

**依赖安装：**
```bash
cd frontend
npm install
```

**启动命令：**
```bash
# 开发模式
npm run dev

# 生产构建
npm run build
# 构建产物在dist/目录中
```

**代理配置：**
前端Vite已配置代理到后端服务：
```typescript
// vite.config.ts
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8083',
      changeOrigin: true
    }
  }
}
```

**页面路由：**
- `/` - 首页（岗位选择）
- `/interview` - 面试页面
- `/report/:id` - 面试报告详情页
- `/about` - 关于页面

## 端口说明

| 服务 | 端口 | 用途 | 访问地址 |
|------|------|------|----------|
| Flask后端 | 8083 | 业务API接口 | http://localhost:8083 |
| 前端开发服务器 | 5173 | Web界面 | http://localhost:5173 |

**端口冲突处理：**

如果端口被占用，可以：

1. **修改后端端口**：
   - 在`backend/flask-backend/app/config/default.py`中修改`SERVER_PORT`
   - 在`.env`文件中设置`SERVER_PORT=新端口`

2. **修改前端代理端口**：
   - 在`frontend/vite.config.ts`中修改代理目标端口

## 常见问题

### 1. Python虚拟环境问题

**错误信息：** `ModuleNotFoundError` 或虚拟环境相关错误

**解决方案：**
```bash
# 重新创建虚拟环境
cd backend/flask-backend
rm -rf venv  # 删除旧虚拟环境
python -m venv venv

# Windows激活
venv\Scripts\activate

# Linux/Mac激活
source venv/bin/activate

# 重新安装依赖
pip install -r requirements.txt
```

### 2. MySQL连接失败

**错误信息：** `OperationalError` 或数据库连接失败

**解决方案：**
1. 确保MySQL服务已启动
2. 检查`.env`文件中的数据库配置
3. 确认数据库`ai_interview`已创建
4. 检查MySQL用户权限

### 3. Node.js版本不兼容

**错误信息：** Node版本相关警告或错误

**解决方案：**
- 安装Node.js 20.19.0或更高版本
- 下载地址：https://nodejs.org/
- 或使用nvm管理Node版本

### 4. 前端无法连接后端API

**错误信息：** 网络请求失败或CORS错误

**解决方案：**
1. 检查后端服务是否正常运行（访问http://localhost:8083/health）
2. 确认前端代理配置正确
3. 检查浏览器开发者工具中的网络请求

### 5. 语音服务异常

**错误信息：** ASR/TTS服务调用失败

**解决方案：**
1. 检查科大讯飞API密钥是否正确配置
2. 确保网络可以访问讯飞API
3. 如需音频格式转换，安装ffmpeg并添加到PATH

### 6. 数据库初始化失败

**错误信息：** `init_db.py`执行失败

**解决方案：**
1. 手动执行SQL语句创建数据库：
   ```sql
   CREATE DATABASE IF NOT EXISTS ai_interview 
   DEFAULT CHARACTER SET utf8mb4 
   COLLATE utf8mb4_unicode_ci;
   ```
2. 检查MySQL用户权限
3. 检查数据库连接配置

### 7. RAG功能加载慢

**原因：** 首次加载需要下载或加载嵌入模型

**解决方案：**
- 耐心等待模型加载完成（可能需几分钟）
- 确保模型文件在`models/bge-large-zh/`目录中
- 检查网络连接

## 生产部署建议

### 后端部署
```bash
# 使用gunicorn部署
gunicorn -w 4 -b 0.0.0.0:8083 "app:create_app()"

# 或使用Docker
docker build -t ai-interview-flask .
docker run -p 8083:8083 --env-file .env ai-interview-flask
```

### 前端部署
```bash
# 构建生产版本
npm run build

# 使用nginx或类似服务器部署dist/目录
```

### 注意事项
1. **API密钥安全**: 生产环境务必使用自己的API密钥
2. **数据库备份**: 定期备份MySQL数据库
3. **日志管理**: 配置适当的日志记录和监控
4. **性能优化**: 根据实际负载调整gunicorn工作进程数
