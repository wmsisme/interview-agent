## 环境要求

- MySQL 8.0+
- Python 3.7+（用于自动初始化脚本）
- 数据库连接配置（在.env文件中）

默认数据库配置：
```bash
DB_HOST=localhost
DB_PORT=3306
DB_NAME=ai_interview
DB_USER=root
DB_PASSWORD=123456
```

## 快速初始化

### 方式一：使用Python脚本（推荐）

项目提供了自动初始化脚本：

```bash
cd backend/flask-backend

# 确保虚拟环境已激活
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 执行初始化脚本
python init_db.py
```

脚本会自动：
1. 创建数据库（如果不存在）
2. 创建所有数据表
3. 插入测试数据（可选）

### 方式二：使用Flask命令

```bash
cd backend/flask-backend

# 激活虚拟环境后
flask db init      # 初始化迁移仓库（首次）
flask db migrate   # 创建迁移脚本
flask db upgrade   # 执行迁移
```

## 手动初始化

如果自动脚本无法使用，可以手动执行SQL语句。

### 步骤1：创建数据库

```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS ai_interview 
DEFAULT CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

-- 使用数据库
USE ai_interview;
```

### 步骤2：创建用户表

```sql
CREATE TABLE IF NOT EXISTS user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    password VARCHAR(255) NOT NULL COMMENT '密码',
    email VARCHAR(100) COMMENT '邮箱',
    phone VARCHAR(20) COMMENT '手机号',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_username (username),
    INDEX idx_email (email)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 步骤3：创建面试记录表

```sql
CREATE TABLE IF NOT EXISTS interview_record (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '面试ID',
    user_id BIGINT NOT NULL COMMENT '用户ID',
    position VARCHAR(100) NOT NULL COMMENT '面试岗位（如java_backend, web_frontend）',
    start_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '开始时间',
    end_time TIMESTAMP NULL COMMENT '结束时间',
    overall_score DECIMAL(5,2) COMMENT '综合得分',
    report TEXT COMMENT '面试报告JSON',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_user_id (user_id),
    INDEX idx_position (position),
    FOREIGN KEY (user_id) REFERENCES user(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='面试记录表';
```

### 步骤4：创建问答记录表

```sql
CREATE TABLE IF NOT EXISTS question_answer (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '问答ID',
    interview_id BIGINT NOT NULL COMMENT '面试ID',
    question TEXT NOT NULL COMMENT '问题内容',
    answer TEXT COMMENT '回答内容',
    tech_score DECIMAL(5,2) COMMENT '技术深度分(0-10)',
    depth_score DECIMAL(5,2) COMMENT '理解深度分(0-10)',
    logic_score DECIMAL(5,2) COMMENT '逻辑清晰度分(0-10)',
    match_score DECIMAL(5,2) COMMENT '岗位匹配度分(0-10)',
    feedback TEXT COMMENT 'AI反馈意见',
    next_question TEXT COMMENT '下一问题',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_interview_id (interview_id),
    FOREIGN KEY (interview_id) REFERENCES interview_record(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='问答记录表';
```

### 步骤5：插入测试数据（可选）

```sql
-- 插入测试用户
INSERT INTO user (username, password, email, phone) VALUES
('test_user', 'test_password_hash', 'test@example.com', '13800138000')
ON DUPLICATE KEY UPDATE username='test_user';

-- 插入测试面试记录

(1, 'java_backend', NOW())
ON DUPLICATE KEY UPDATE position='java_backend';

-- 插入测试问答记录

(1, '请介绍一下Java中的HashMap原理？', NOW());
```

## 常见问题

### Q1: 数据库连接失败

**错误信息：** `OperationalError: (2003, "Can't connect to MySQL server")`

**解决方案：**
1. 确保MySQL服务已启动
2. 检查数据库配置（DB_HOST, DB_PORT）
3. 检查防火墙设置
4. 验证数据库用户权限

### Q2: 权限不足

**错误信息：** `Access denied for user`

**解决方案：**
1. 检查用户名和密码
2. 授予用户权限：
   ```sql
   GRANT ALL PRIVILEGES ON ai_interview.* TO 'your_user'@'localhost';
   FLUSH PRIVILEGES;
   ```

### Q3: 表已存在

**错误信息：** `Table 'xxx' already exists`

**解决方案：**
1. 这是正常提示，可以忽略
2. 如需重新创建，先删除表：
   ```sql
   DROP TABLE IF EXISTS question_answer;
   DROP TABLE IF EXISTS interview_record;
   DROP TABLE IF EXISTS user;
   ```

### Q4: 字符集问题

**错误信息：** `Unknown character set`

**解决方案：**
1. 确保使用utf8mb4字符集
2. 检查MySQL版本（需要8.0+）

### Q5: 外键约束失败

**错误信息：** `Cannot add or update a child row`

**解决方案：**
1. 确保先创建父表（user）再创建子表
2. 插入数据时确保外键值存在

## 使用MySQL Workbench

如果命令行工具不可用，可以使用MySQL Workbench图形界面：

1. **打开MySQL Workbench**
2. **连接到本地MySQL服务器**
   - Host: `localhost`
   - Port: `3306`
   - Username: `root`
   - Password: `123456`
3. **打开SQL脚本**
   - 点击菜单：`File` → `Open SQL Script`
   - 选择SQL文件或复制粘贴SQL语句
4. **执行脚本**
   - 点击执行按钮（闪电图标 ⚡）
   - 查看输出结果
