## 三、功能验收

### 3.1 岗位化情景模拟

| 序号 | 验收项 | 验收标准 | 结果 |
|------|--------|----------|------|
| 1.1 | 岗位数量 | 至少支持两种计算机专业岗位（Java后端开发工程师、Web前端开发工程师） | |
| 1.2 | 岗位切换 | 用户可选择岗位，系统根据岗位加载对应题库与评估模型 | |
| 1.3 | 差异化题目 | 不同岗位面试题目有明显差异（如后端侧重数据库、并发，前端侧重JS、框架） | |
| 1.4 | 岗位知识库 | 为每个岗位构建专属的知识库，用于RAG检索 | |

### 3.2 多模态互动面试

| 序号 | 验收项 | 验收标准 | 结果 |
|------|--------|----------|------|
| 2.1 | 文本输入 | 支持用户通过键盘输入回答，消息实时显示 | |
| 2.2 | 语音输入 | 支持用户通过麦克风录音输入，录音结束后自动发送 | |
| 2.3 | 语音播放 | AI回复时自动播放语音（可手动控制开关） | |
| 2.4 | 多轮对话 | AI能根据用户回答进行智能追问，模拟真实面试节奏 | |
| 2.5 | 会话保持 | 面试过程中对话历史完整保留，刷新页面不丢失（或提示恢复） | |

### 3.3 能力评估与深度反馈

| 序号 | 验收项 | 验收标准 | 结果 |
|------|--------|----------|------|
| 3.1 | 多维度评分 | 对每个回答从技术正确性、知识深度、逻辑清晰度、表达流畅度、岗位匹配度五个维度评分（0-10分） | |
